# Print Export Guide

This folder contains PDF-ready HTML manuals:

- USER_MANUAL_EN_PRINT.html
- USER_MANUAL_ES_PRINT.html
- print-manual.css

## Export to PDF (Recommended)

1. Open one HTML file in a browser.
2. Use Print (Cmd+P on macOS).
3. Destination: Save as PDF.
4. Enable background graphics.
5. Paper size: A4.
6. Margins: Default (CSS already defines page margins).
7. Scale: 100%.
8. Save output file.

## Suggested Output Names

- ekklesiaONLINE_User_Manual_EN.pdf
- ekklesiaONLINE_Manual_de_Usuario_ES.pdf

## Notes

- The layout includes a cover page and table of contents.
- Section breaks are optimized for printing.
- If your browser overrides margins, keep scaling at 100% and disable custom margin overrides.
